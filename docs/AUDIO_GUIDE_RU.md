# LECTA: краткое руководство по паузам и очистке MP3

## Запуск

Нужны Python и FFmpeg в `PATH`. Для текущего набора зависимостей используйте Python 3.12 (на нём проверена установка); общая инструкция проекта указывает Python 3.11+. В PowerShell из каталога проекта создайте окружение (если ещё нет), установите зависимости и запустите приложение:

```powershell
Set-Location 'C:\LEСTA\fb2tts'
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Если окружение уже подготовлено, активируйте его вместо создания нового. Проверьте, что команда `python` относится именно к нему и `edge-tts` имеет версию 7.3.x:

```powershell
python -c "import edge_tts; print(edge_tts.__version__)"
```

Откройте `http://127.0.0.1:7860`. Для облачных голосов Edge нужна сеть. Локальным голосам могут потребоваться модели; их загрузка доступна во вкладке **System & Cleanup**.

## Очистить паузы в MP3

1. Откройте вкладку **✂️ Remove pauses**.
2. Добавьте MP3 одним из способов: загрузите файлы, отметьте проекты LECTA или укажите пути к файлам/папкам (по одному на строку). Нажмите **Load selected audio**.
3. Выберите профиль, при необходимости настройте **Cleaning and quality settings**.
4. Нажмите **Analyze**, чтобы посмотреть длительность, суммарную тишину, самую длинную паузу и тишину в начале/конце.
5. Выберите файл в **Audio to preview** и нажмите **Preview before / after**. Прослушайте обе версии.
6. Отметьте файлы для обработки в **Files to clean** и нажмите **Clean selected batch**. Результаты появятся в таблице; ZIP можно скачать кнопкой **Download cleaned ZIP**, папку — открыть кнопкой **Open output folder**. Остановить пакетную обработку можно кнопкой **Cancel**.

### Профили очистки

- **Compact (default)** — безопасный начальный выбор: сокращает явно длинные паузы, оставляя короткое дыхание. Порог −38 dBFS, паузы от 0,35 с, сохраняемый фрагмент паузы 110 мс.
- **Natural** — сохраняет больше разговорного ритма и воздуха. Порог −40 dBFS, паузы от 0,45 с, сохраняемый фрагмент 220 мс.
- **Aggressive — preview first** — удаляет больше тишины, но может срезать тихие согласные. Обязательно проверьте предварительное прослушивание и результат.

Ползунок **Silence threshold (dBFS)** задаёт порог обнаружения тишины: более низкое значение консервативнее и лучше защищает тихую речь. **Minimum gap to shorten** задаёт минимальную длину паузы для сокращения; **Pause to keep** — сколько оставить внутри неё. **Trim excessive silence at file edges** включает обработку тишины в начале и конце. Битрейт задаёт качество/размер нового MP3.

### Важно

- Исходный MP3 не перезаписывается. Очищенная копия сохраняется рядом с ним; если имя занято, к имени добавляется суффикс. При невозможности записи рядом с исходником используется `data/_audio_tools/`.
- Меняются только интервалы, которые алгоритм обнаружил как тишину по выбранному порогу. Результат всё равно нужно прослушать: слишком высокий порог способен принять тихие звуки речи за тишину.
- Если подходящих пауз нет, файл пропускается без изменений. Ошибка чтения, кодирования или проверки результата отображается как ошибка, а не как успешная обработка.

## Паузы при синтезе — это отдельная настройка

Профили очистки выше предназначены для уже готовых MP3. Для пауз при создании аудио используйте боковую панель **Pause profile**: `compact` (короткие паузы, по умолчанию), `natural` (больше воздуха) или `learning` (длинные паузы). Настройки с подробными интервалами находятся в **Settings → Audio & pauses**. Не путайте профиль генерации с профилем очистки: у них разные наборы вариантов.

### Паузы внутри фразы (важно)

Движок синтеза ставит паузы сам: F5-TTS дышит на запятых и точках, а Edge TTS присылает готовые предложения со своими внутренними перерывами. Раньше политика пауз управляла только склейками между фрагментами, поэтому даже профиль `compact` звучал рвано: в готовом файле замерялось до 35 % тишины и 340 пауз со средним значением 0,52 с.

Теперь любая тишина **внутри** фрагмента длиннее лимита сокращается до него. Ползунок **Max pause inside a phrase** есть и в боковой панели, и в **Settings → Audio & pauses**:

| Профиль | `pause_internal_ms` по умолчанию |
|---|---|
| compact | 250 мс |
| natural | 400 мс |
| learning | 700 мс |

Поставьте 150 мс для максимально плотного чтения. Ограничение действует и для переднего плана, и для фоновой генерации (`worker.py` получает значение через `generation_settings()`). Обрезка краёв фрагмента выполняется по огибающей (RMS, шаг 20 мс) с порогом −45 dB от пика фрагмента и абсолютным полом −48 dBFS, поэтому шумовой хвост движка после последнего слова не добавляется к настроенной паузе.
