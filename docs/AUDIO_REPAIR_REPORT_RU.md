# Инженерный отчёт: исправление аудиопауз и обработка ошибок TTS

**Дата проверки:** 15 ноября 2026 г.  
**Область:** изменённый multilingual router, Edge TTS dependency, политика пауз, MP3-cleaner и пакетные тесты. Это отчёт о проверенных локальных изменениях, а не утверждение о полном приёмочном тестировании приложения.

## Краткий вывод

Исправлен путь, по которому ошибки Edge TTS, включая HTTP 403, в старом router незаметно превращались в 2,5 секунды тишины; теперь сохраняющаяся ошибка синтеза приводит к ошибке всего файла, а не к тихому заполнителю. Заданы управляемые паузы между фрагментами; добавлен отдельный неразрушающий инструмент сокращения пауз в готовых MP3. Проверены unit tests, компиляция Python-файлов и аудиопроход с живым Microsoft Edge TTS для русского, английского и иврита. UI в браузере прошёл smoke-test, изолированный detached worker проверен на временных данных; запуск worker через реальную кнопку и полное визуальное тестирование приложения не завершены.

## Что изменено по коду

- `libs/multilingual_router.py`: ошибка Edge TTS теперь проходит через повторы и, для достаточно длинного текста, повторную попытку на половинах; при сохраняющейся ошибке router поднимает `RuntimeError`, а не подставляет тишину. Пропавший/пустой/полностью тихий результат локального синтеза также трактуется как ошибка. Границы фрагментов соединяются явными паузами, без наложения речи; для краёв фрагментов задан щадящий порог обработки, чтобы сохранять тихие согласные. Пресеты генерации `compact`, `natural`, `learning` настраивают интервалы и предел явного `<break>`.
- `requirements.txt`: диапазон изменён с `edge-tts>=6.1,<7.0` на `edge-tts>=7.3,<8.0`. В используемом виртуальном окружении `C:\LEСTA\venv` фактически установлен `edge-tts 7.3.1` (Python 3.12.7). В системном Python 3.14 отдельно остаётся `edge-tts 7.2.8`; это не версия установленного в проверенном окружении проекта пакета. Следует запускать приложение из корректного окружения и проверять `python -c "import edge_tts; print(edge_tts.__version__)"`.
- `libs/audio_tools.py`, `gr_tabs/audio_tools_tab.py`, настройки и подключение в `app.py`: добавлены анализ, предпросмотр, пакетная очистка и проверка MP3, а также управление профилями очистки. Сохранение создаёт отдельный файл и проверяет результат; исходник не перезаписывается.
- `worker.py` и связанные изменения: обработка ошибок синтеза и сборка фонового пакета стали явными; в тесты добавлен headless-путь для функций Gradio и проверки package-сборки.

## Границы подтверждения и замечания

- Подтверждена загрузка актуального Gradio UI в Tabbit и отображение шести вкладок, включая **✂️ Remove pauses**; cleaner и Settings с секцией **🎚 Audio & pauses** открывались в браузере. Два скриншота сохранены в `samples/ui_20261115/`: `cleaner_css1365.png` (измеренная CSS-ширина 1365 px) и `settings_audio_pauses.png`. Попытка корректно снять и измерить все запрошенные сочетания viewport/zoom не завершена: браузер использует нестандартный DPR, узкие вкладки уходят в overflow, а screenshot Playwright зависает на шрифтах. Поэтому адаптивность на всём наборе размеров/масштабов не считается подтверждённой.
- Отдельно проверен detached worker: child процесс пережил завершение launcher и создал статус и трёхфайловый пакет на временных данных. Это не равнозначно запуску через реальную кнопку GUI и принудительному закрытию GUI-процесса.
- **Не подтверждены:** полное интерактивное UI-тестирование cleaner, все requested viewport/zoom-пары и detached worker через реальный GUI. Наличие Python unit tests не является доказательством этих сценариев.
- Обновлён `docs/USAGE.md`: добавлены актуальные разделы по профилям пауз, detached/background TTS, пакету из трёх файлов и вкладке **✂️ Remove pauses**; описание интервала смены языка больше не фиксировано.
- Вкладки и подписи интерфейса преимущественно английские; данное краткое руководство по новой обработке написано по-русски.
- **Aggressive** может срезать тихие согласные. Пользователю следует сначала выполнить Analyze и Preview before / after. Исходный MP3 сохраняется, но безопасная проверка не может заменить прослушивание.
